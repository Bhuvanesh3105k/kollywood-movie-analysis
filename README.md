# kollywood-movie-analysis
Kollywood Movie Data Analysis

Project Overview

This project focuses on analyzing Tamil movie data using Python to understand movie ratings, popularity, and trends.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

Analysis Performed

- Data Loading and Exploration
- Data Cleaning
- Best Movie Analysis
- Average Movie Analysis
- Popular Movie Analysis
- Vote Average Analysis

Key Findings

- Identified the best-rated movies.
- Analyzed average movie ratings.
- Identified popular movies based on popularity scores.
- Explored movie data and trends.

Conclusion

This project helped me gain practical experience in data analysis using Python libraries.
